Карточка карты

Всю информацию об отдельно взятой карте можно посмотреть на специальной странице - своеобразной карточке каталога. Например, вот страничка карты ЧР'2024 в Петропавловской крепости: https://o-maps.spb.ru/map-info.html?map=petropavlovka_2024. Заменяя значение параметра map в адресе на имя файла нужной карты, можно получить ссылку на её страничку. Но можно попасть сюда и проще - щёлкнув по скрепке (🔗) справа от названия карты во всплывающем окне с информацией о ней.

На этой странице - три вкладки: Информация, Карта и Документы. Первая из них во многом дублирует всплывающее окошко информации о карте на общей странице, разве что в другом дизайне: GPS-трансляция, авторы, владельцы и список соревнований, проводившихся по этой карте (со ссылками на результаты и страницы стартов). На второй можно посмотреть и скачать собственно карту и, возможно, какие-то ещё сопутствующие материалы (карты, информационные бюллетени, протоколы результатов, фотографии для фото-квестов и пр.). Если правообладатель не разрешил просмотр карты, на этой вкладке будет соответствующее сообщение. На третьей вкладке, если они есть, собраны сканы связанных с картой документов.

Каталог многодневки

Список карт любого соревнования, зарегистрированного в каталоге, можно посмотреть в наглядной форме в виде плиток. Например, по такому адресу откроется страница карт московской серии Аэророгейн. Заменяя значение параметра start в адресе на код нужного соревнования, можно получить ссылку на его страничку. Список всех зарегистрированных стартов и их коды можно посмотреть тут: https://github.com/efradkin/o-maps/blob/main/js/starts.js. Но можно попасть сюда и проще - щёлкнув по специальной кнопке в правой части заголовка страницы сводной таблицы при включении фильтрации по нужному старту.

На странице соревнования две вкладки: «Календарь» - все старты этого соревнования из календаря, и «Карты» - собственно плитки. Щёлкнув по любой из плиток, Вы попадёте на страницу информации о соответствующей карте. Подробнее о соревнованиях - в разделе «Соревнования».
