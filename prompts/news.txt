Содержимое страницы новостей https://o-maps.spb.ru/news.html берётся непосредственно из телеграм-канала https://t.me/o_maps_channel. Каждому (ну почти) посту канала соответствует запись на странице. Все файлы сайта - в открытом доступе. Можешь ли ты сформировать архив файлов, которые надо заменить на сайте, чтобы дополнить страницу недостающими постами? Если надо, я могу прислать архив файлов экспорта из канала.

Вот файлы экспорта из канала. И вот скрипт с массивом записей новостей, который надо обновить.
Вот пример записи в скрипте:

{
    date: '2026-07-19',
    title: 'Маршруты',
    info: '<a href="tracks.html">Добавил</a> три недостающих маршрута забегов "5 Вёрст" (бывший Parkrun) - Оккервиль, Мурино и Кронштадт.<br>Заодно реализовал возможность отфильтровать список маршрутов по коду соревнования. Например, <a href="sheet-tracks.html?start=PARKRUN">вот</a> таблица всех забегов "5 Вёрст", а <a href="sheet-tracks.html?start=KVMLO">вот</a> треки Кубка веломарафонов ЛО, а <a href="sheet-tracks.html?start=TOKSOVO_CUP">тут</a> лыжные гонки ToksovoCup, ну и т.д.',
    pics: ['2026-07-19_1', 2]
},
date - дата из поста
title - пиши тут просто "ЗАГОЛОВОК"
info - это html-содержимое поста (без последнего абзаца со ссылками, который одинаковый во всех постах)
pics - массив из двух элементов: имя папки с фотками и количество фоток в посте.

Фотки поста кладутся в подпапки директории news.
Имя папки с фотками обычно совпадает с датой поста, но если у нас несколько постов в день, то добавляем суффиксы "_1", "_2" и т.д. Для каждой фотки есть основная (с именем pic_*.jpg) и уменьшенная (thumb_*.jpg), где * - это номер фотки. Фотки берутся непосредственно из папки с экспортом канала и переименовываются, как указано выше. Но ещё уменьшенные фотки (thumbs) надо уменьшить в два раза (пропорцинально по каждой стороне, используя какой-нибудь современный алгоритм для максимальной резкости и сохранения деталей).
Важные посты помечать не надо, и ничего не пропускай.

Проверь - для уменьшенных фоток надо брать файлы с суффиксом "_thumb" из экспорта канала, а в качестве основных картинок (pic_*.jpg) - те, что без этого суффикса. Это важно.
